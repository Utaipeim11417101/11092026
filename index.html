一、專案架構與教學設計

本專案為國中生活科技課程（機構與結構單元，如槓桿、連桿、齒輪組或彈珠台機構設計）量身打造。學生可以在前端網頁進行手繪構想設計，系統會即時記錄學生的互動歷程，並在最後將圖像與歷程傳送至 Google Gemini AI 進行診斷與專業回饋。

1. 課程教學目標

  • 科技手繪表達：練習運用線條、顏色與基本形狀表達機關運作邏輯（如標示支點、作用點、連桿方向）。
  • 思考歷程記錄：記錄學生的作畫時間、修改次數、畫筆筆劃，培養問題解決與迭代修改之習慣。
  • AI 輔助學習診斷：AI 作為科技導師，即時評估結構可行性、材料合理性，並提供個人化提問與優化建議。

2. 系統運作架構圖

互動流程：
[學生前端 UI] ➔ 繪圖板互動 + 歷程收集 (畫筆劃數/繪畫耗時/註解) ➔ 按下「送出 AI 評估」 ➔ POST 請求至 [Google Apps Script Web App] ➔ 呼叫 [Google Gemini 2.5 Flash API] ➔ 回傳結構分析與建議 ➔ 渲染回 [學生前端頁面]

二、Google Apps Script (GAS) 建置步驟說明

  1. 取得 Google Gemini API Key

    造訪 Google AI Studio，登入 Google 帳號後點擊 "Get API key"，建立並複製一組 API 金鑰。

  2. 建立 Google Apps Script 專案

    開啟 Google Apps Script 雲端硬碟主頁，點選左上角「新增專案」。將專案命名為「生活科技AI繪圖評估系統」。

  3. 設定指令碼屬性 (Script Properties) 保存 API Key

    點選專案左側齒輪圖示（專案設定），捲動至下方「指令碼屬性」，新增一筆屬性：
    名稱：GEMINI_API_KEY
    值：貼上剛才複製的 API 金鑰。

  4. 建立 `Code.gs` 與 `Index.html` 檔案

    點選左側「程式碼編輯器 (< / >)」，將預設的 `Code.gs` 替換為下方提供之 Code.gs 程式碼。點選新增檔案選單 (+) 選擇「HTML」，建立檔名為 `Index.html` 的檔案並貼入對應程式碼。

  5. 發布部署為 Web 應用程式 (Web App)

    點選右上角「部署」 ➔ 「新增部署」 ➔ 種類選擇「Web 應用程式」。
    - 執行身份：我 (Me)
    - 誰有存取權：所有人 (Anyone)（適合讓學生無需登入即能操作）。
    完成部署後複製取得的 Web App URL 即可發布給學生使用！

（提出一個具啟發性的問題，引導學生進行第二次修改）
`;

    // 呼叫 Gemini 2.5 Flash 視覺 API
    const url = `https://generativelanguage.googleapis.com/v1beta/models/gemini-2.5-flash:generateContent?key=${apiKey}`;
    
    const requestBody = {
      contents: [{
        parts: [
          { text: promptText },
          {
            inline_data: {
              mime_type: "image/png",
              data: base64Image
            }
          }
        ]
      }]
    };

    const options = {
      method: "post",
      contentType: "application/json",
      payload: JSON.stringify(requestBody),
      muteHttpExceptions: true
    };

    const response = UrlFetchApp.fetch(url, options);
    const json = JSON.parse(response.getContentText());

    if (json.candidates && json.candidates[0].content.parts[0].text) {
      const aiReply = json.candidates[0].content.parts[0].text;
      return { success: true, feedback: aiReply };
    } else {
      return { success: false, message: 'AI 分析失敗：' + JSON.stringify(json) };
    }

  } catch (err) {
    return { success: false, message: '伺服器內部錯誤：' + err.toString() };

<script>
  // --- 畫布與互動歷程記錄器變數 ---
  const canvas = document.getElementById('sketchCanvas');
  const ctx = canvas.getContext('2d');
  let isDrawing = false;
  let currentMode = 'brush';
  
  let strokeCount = 0;
  let resetCount = 0;
  let startTime = Date.now();

  // 初始化畫布背景為白色
  ctx.fillStyle = '#ffffff';
  ctx.fillRect(0, 0, canvas.width, canvas.height);

  // 定期更新作畫時間
  setInterval(() => {
    const elapsed = Math.floor((Date.now() - startTime) / 1000);
    document.getElementById('timerDisplay').innerText = elapsed;
  }, 1000);

  // 繪圖事件監聽
  canvas.addEventListener('mousedown', startDrawing);
  canvas.addEventListener('mousemove', draw);
  canvas.addEventListener('mouseup', stopDrawing);
  canvas.addEventListener('mouseleave', stopDrawing);

  // 觸控支援 ( iPad / 觸控螢幕 )
  canvas.addEventListener('touchstart', (e) => { e.preventDefault(); startDrawing(e.touches[0]); });
  canvas.addEventListener('touchmove', (e) => { e.preventDefault(); draw(e.touches[0]); });
  canvas.addEventListener('touchend', stopDrawing);

  function getPos(e) {
    const rect = canvas.getBoundingClientRect();
    return { x: e.clientX - rect.left, y: e.clientY - rect.top };
  }

  function startDrawing(e) {
    isDrawing = true;
    const pos = getPos(e);
    ctx.beginPath();
    ctx.moveTo(pos.x, pos.y);
    strokeCount++;
    document.getElementById('strokeCountDisplay').innerText = strokeCount;
  }

  function draw(e) {
    if (!isDrawing) return;
    const pos = getPos(e);
    ctx.lineWidth = document.getElementById('lineWidth').value;
    ctx.lineCap = 'round';

    if (currentMode === 'eraser') {
      ctx.strokeStyle = '#ffffff';
    } else {
      ctx.strokeStyle = document.getElementById('colorPicker').value;
    }

    ctx.lineTo(pos.x, pos.y);
    ctx.stroke();
  }

  function stopDrawing() {
    if (isDrawing) {
      ctx.closePath();
      isDrawing = false;
    }
  }

  function setMode(mode) {
    currentMode = mode;
  }

  function clearCanvas() {
    ctx.fillStyle = '#ffffff';
    ctx.fillRect(0, 0, canvas.width, canvas.height);
    resetCount++;
    document.getElementById('resetCountDisplay').innerText = resetCount;
  }

  // --- 送出資料至 GAS 後端 ---
  function submitData() {
    const name = document.getElementById('studentName').value.trim();
    if (!name) {
      alert('請填寫班級座號姓名！');
      return;
    }

    const payload = {
      studentName: name,
      topic: document.getElementById('topic').value,
      description: document.getElementById('description').value,
      imageBase64: canvas.toDataURL('image/png'),
      analytics: {
        strokeCount: strokeCount,
        drawingTimeSeconds: Math.floor((Date.now() - startTime) / 1000),
        resetCount: resetCount
      }
    };

    // 顯示載入動畫
    document.getElementById('loadingBox').style.display = 'block';
    document.getElementById('resultBox').style.display = 'none';

    // 呼叫 GAS 後端函式 processStudentSubmission
    google.script.run
      .withSuccessHandler(onSuccess)
      .withFailureHandler(onFailure)
      .processStudentSubmission(JSON.stringify(payload));
  }

  function onSuccess(response) {
    document.getElementById('loadingBox').style.display = 'none';
    const resultBox = document.getElementById('resultBox');
    resultBox.style.display = 'block';

    if (response.success) {
      document.getElementById('aiFeedbackContent').innerText = response.feedback;
    } else {
      document.getElementById('aiFeedbackContent').innerText = '❌ 發生錯誤：' + response.message;
    }
  }

  function onFailure(error) {
    document.getElementById('loadingBox').style.display = 'none';
    alert('通訊失敗：' + error.message);
  }
</script>

五、教學應用與擴充建議

1. 課堂實施建議

教師可先在課堂前 10 分鐘解說機構基本概念（如三種槓桿型態或連桿機制），隨後讓學生開啟此 Web App 進行 15 分鐘草圖設計與思考筆記填寫。學生點擊送出後，AI 老師會立即針對繪圖給予一對一的診斷與問題引導。

2. 整合 Google Sheets 自動記錄學習歷程
